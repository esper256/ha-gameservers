Dedicated [Minecraft](https://www.minecraft.net/) Java multiplayer server for Home Assistant OS. Each world pins a Minecraft version. Drop mods on the LAN upload page and the loader (Fabric, NeoForge, or vanilla) is chosen from those jars. AutoModpack syncs clients when a loader is in use.

Use the **Documentation** tab before the first start. After it is running, manage worlds with **Open Web UI**. The mod-upload page uses the host port from the add-on **Network** settings (default 8765; not a Home Assistant login).
