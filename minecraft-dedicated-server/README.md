Dedicated [Minecraft](https://www.minecraft.net/) Java multiplayer server for Home Assistant OS. Each world can use Fabric or NeoForge. Kids drop a built JAR on a LAN upload page; AutoModpack syncs the rest.

Use the **Documentation** tab before the first start. After it is running, manage worlds with **Open Web UI**. Kids use the upload page on port **8765**, not Home Assistant accounts.
